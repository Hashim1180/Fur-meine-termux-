# 🚀 Deployment Guide - AW Gyms on Vercel\n\n## 📋 Prerequisites\n\n1. **GitHub Repository** - Connected to Vercel\n2. **Database** - MySQL (PlanetScale recommended) or Vercel MySQL\n3. **Domain** - awgyms.com configured in Vercel\n\n## 🔧 Step 1: Database Setup\n\n### Option A: PlanetScale (Recommended)\n\n1. Go to https://app.planetscale.com\n2. Create a new database\n3. Click \"Connect\" and select \"Node.js\"\n4. Copy the connection string:\n   ```\n   mysql://[username]:[password]@[host]/[database]\n   ```\n\n### Option B: Local MySQL\n\n```sql\nCREATE DATABASE awgyms CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;\n```\n\n## 🔐 Step 2: Set Environment Variables in Vercel\n\n1. Go to **Vercel Dashboard** → Your Project → **Settings** → **Environment Variables**\n2. Add these variables:\n\n```\nKey: APP_ID\nValue: awgyms-production\n\nKey: APP_SECRET\nValue: <strong-random-32-char-key>\n\nKey: DATABASE_URL\nValue: mysql://user:password@host/database\n\nKey: NODE_ENV\nValue: production\n```\n\n**Generate strong APP_SECRET:**\n```bash\nnode -e \"console.log(require('crypto').randomBytes(24).toString('hex'))\"\n```\n\n## 📊 Step 3: Database Migrations\n\n**Option A: Auto-migrate on deploy (Recommended)**\n\nVercel will automatically run `npm run db:push` during build.\n\n**Option B: Manual migration**\n\nRun this once after deployment:\n```bash\ncd app\nDATABASE_URL=<your-url> npm run db:push\n```\n\n## 🌐 Step 4: Configure Domain\n\n1. **Vercel Dashboard** → **Settings** → **Domains**\n2. Add domain: `awgyms.com`\n3. Add subdomain: `www.awgyms.com`\n4. Update your DNS provider with Vercel's CNAME records:\n\n```\nName: awgyms.com\nType: CNAME\nValue: cname.vercel-dns.com.\n\nName: www.awgyms.com\nType: CNAME\nValue: cname.vercel-dns.com.\n```\n\n## ✅ Step 5: Deploy\n\n```bash\n# Push to main branch\ngit push origin main\n```\n\nVercel automatically:\n1. ✅ Installs dependencies\n2. ✅ Runs database migrations\n3. ✅ Builds React frontend\n4. ✅ Bundles Node.js backend\n5. ✅ Deploys globally\n\n## 🔍 Verify Deployment\n\n### Health Check\n```bash\ncurl https://awgyms.com/health\n# Expected response:\n# {\"status\":\"ok\",\"timestamp\":\"2024-01-01T...\",\"environment\":\"production\"}\n```\n\n### Check Logs\n1. **Vercel Dashboard** → **Deployments** → Latest → **Logs**\n2. Check for:\n   - ✅ `Database connection established`\n   - ✅ `Server running at`\n   - ✅ `Static files served from`\n\n## 🛠️ Build Command Explained\n\n```json\n\"buildCommand\": \"cd app && npm ci && npm run db:push && npm run build\"\n```\n\n1. `cd app` - Navigate to app directory\n2. `npm ci` - Clean install dependencies\n3. `npm run db:push` - Sync database schema\n4. `npm run build` - Build React + Node.js\n\n## 📈 Performance Optimizations\n\n✅ **Frontend**\n- React code splitting\n- Asset minification\n- Gzip compression\n\n✅ **Backend**\n- Connection pooling (10 concurrent)\n- Error logging\n- Request logging\n\n✅ **Database**\n- PlanetScale auto-scaling\n- Connection pooling\n- Query optimization\n\n## 🚨 Troubleshooting\n\n### Build Fails\n\n**Error:** `DATABASE_URL is required`\n\n**Solution:**\n1. Verify DATABASE_URL is set in Vercel environment variables\n2. Ensure it's production value\n\n**Error:** `Node version mismatch`\n\n**Solution:**\n```json\n// In package.json\n\"engines\": {\n  \"node\": \">=18.0.0\"\n}\n```\n\n### Database Connection Fails\n\n**Check connection string format:**\n```\n✅ Correct: mysql://user:password@host/database\n❌ Wrong:   mysql://user:password@host/database?ssl=true\n```\n\n**Test locally first:**\n```bash\nDATABASE_URL=<url> npm run db:push\n```\n\n### API Returns 404\n\n**Verify rewrites in vercel.json:**\n```json\n\"rewrites\": [\n  {\n    \"source\": \"/api/trpc/:path*\",\n    \"destination\": \"/api/boot.ts\"\n  }\n]\n```\n\n### CORS Errors\n\n**Add your domain to boot.ts:**\n```typescript\ncors({\n  origin: [\n    \"https://awgyms.com\",\n    \"https://www.awgyms.com\",\n  ],\n})\n```\n\n## 🔄 Redeployment\n\n**To trigger new deployment:**\n```bash\ngit commit --allow-empty -m \"Trigger redeploy\"\ngit push origin main\n```\n\n**To rollback to previous version:**\n1. **Vercel Dashboard** → **Deployments**\n2. Click on previous deployment\n3. Click **Promote to Production**\n\n## 💾 Database Backups\n\n**PlanetScale:**\n- Automatic daily backups\n- Access via: **Backups** tab in dashboard\n- 1-click restore available\n\n**Manual backup:**\n```bash\nmysqldump -u <user> -p -h <host> <database> > backup.sql\n```\n\n## 🔐 Security Checklist\n\n- [x] Environment variables secured\n- [x] CORS configured for domain\n- [x] API authentication enabled\n- [x] Database connection encrypted (SSL)\n- [x] Admin credentials hashed\n- [x] Security headers added\n- [x] HTTPS enforced\n\n## 📞 Support Resources\n\n- **Vercel Status**: https://www.vercel-status.com\n- **Vercel Docs**: https://vercel.com/docs\n- **PlanetScale Docs**: https://planetscale.com/docs\n- **MySQL Docs**: https://dev.mysql.com/doc\n\n## 🎉 You're Live!\n\nYour application is now running on:\n- **Frontend**: https://awgyms.com\n- **API**: https://awgyms.com/api/trpc\n- **Health**: https://awgyms.com/health\n\nMonitor your deployment in the Vercel Dashboard.\n
